# Elaina 个人作品集

静态作品集网站，可直接发布至 GitHub Pages，无需安装依赖。

## 发布

仓库 Settings → Pages → Deploy from a branch，选择 `main` 和 `/ (root)`，保存。
网站地址：https://xieyusi4936-ops.github.io/elaina_web/

## 当前内容

- 三幕滚动介绍与点击切换：向前时播放两段约 4 秒的角色转场视频，结束后显示介绍文字；向后时使用图片淡化。快速跳出开场时取消视频，直接显示目的区域。
- 视频仅在转场触发时加载，经过 720p / 30fps H.264 压缩，无声、移动端内联播放；播放失败或减少动态效果偏好开启时使用静态画面。
- 个人简介、项目经历为明确标记的占位内容。
- 三个作品入口展示用户提供的视觉素材，尚非正式项目案例。
- 作品弹窗独立滚动，支持关闭按钮、Escape 关闭以及焦点返回。
- 手机布局与减少动态效果偏好支持。
- 桌面鼠标移动时对图片及作品详情施加单层、最多 30fps 的局部透明水面折射（视频播放期间暂停），直接轻微扭曲原画面，无可见圆环叠层；触屏和减少动态效果模式下关闭，静止后恢复原图并停止计算。

## 更新

`index.html`：个人简介、经历、作品卡片及详情占位文字。
`app.js`：作品标题、详情图片、场景交互。
`style.css`：页面样式和移动端布局。
`assets/`：经过压缩的网页图片；原始 PNG 未修改。

本地预览：`python3 -m http.server 8000`。

## 性能优化

三张 WebP 图片合计约 269 KB，两个 720p 视频合计约 1.4 MB。保留较大素材作为源文件，但页面不引用它们。首屏不请求视频；触发转场时才设置视频地址。
